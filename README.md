# chishiki-no-shosai
自分専用の知識の書斎

## 本を追加するときの図解

書籍紹介や目次を確認し、本の内容を把握しやすい形式を `books.js` の `format` に指定する。

- `mindmap`（マインドマップ）: 中心となる考え方から、関係する概念が枝分かれする本。
- `sketchnote`（スケッチノート）: 順番を問わず、必要な考え方や要点を拾って見返す本。
- `timeline`（タイムライン）: 手順、時間の流れ、変化の順番を追うと理解しやすい本。
- `comic`（学習マンガ）: 人のやり取りや選んだ行動の結果を場面で追うと理解しやすい本。

`guide` にその本での読み方を短く記し、`map` の各項目に要点・補足・具体例を書く。学習マンガは、書斎で作った場面とセリフを `panels` に追加する。参照先は `source` に記載し、本文を確認できない場合は `note` に確認した範囲を記す。
