# chishiki-no-shosai
自分専用の知識の書斎

## 本を追加するときの図解

書籍紹介や目次を確認し、本の内容を把握しやすい形式を `books.js` の `format` に指定する。

- `mindmap`（マインドマップ）: 中心となる考え方から、関係する概念が枝分かれする本。
- `sketchnote`（スケッチノート）: 順番を問わず、必要な考え方や要点を拾って見返す本。
- `timeline`（タイムライン）: 手順、時間の流れ、変化の順番を追うと理解しやすい本。
- `comic`（学習マンガ）: 人のやり取りや選んだ行動の結果を場面で追うと理解しやすい本。

`guide` にその本での読み方を短く記し、`map` の各項目に要点・補足・具体例を書く。学習マンガは、書斎で作った場面とセリフを `panels` に追加する。参照先は `source` に記載し、本文を確認できない場合は `note` に確認した範囲を記す。

図解の見せ方は、マインドマップなら中心と枝を結ぶ全体図、スケッチノートなら手描きの挿絵と蛍光線、タイムラインなら手順が並ぶ一本の軸、学習マンガなら人物の表情が見える場面イラストとセリフを使う。文章はスマートフォンで拡大や選択ができるようHTMLで持つ。

図解は書斎の詳細画面で、紙面のように一続きで読める形にする。マインドマップは中心から枝に展開し、枝ごとに要点・補足・具体例を載せる。スケッチノートは手描き挿絵とマーカーで読みどころを示す。タイムラインは番号と一本の軸で順序を伝える。学習マンガは同じ人物が登場する場面イラストを用い、セリフはHTMLで添える。見本の構成を参考に各書籍用の図解を制作する。
